# Introduction to Machine Learning (ML)

> **Quick Definition:**\
> **Machine Learning (ML)** is a branch of Artificial Intelligence (AI)
> that enables computers to **learn patterns from data** and make
> predictions or decisions **without being explicitly programmed** for
> every task.

------------------------------------------------------------------------

# Traditional Programming vs Machine Learning

## Traditional Programming

-   Input Data
-   Program (rules written by a programmer)

``` text
Input Data + Program
          │
          ▼
      Computer
          │
          ▼
        Output
```

## Machine Learning

-   Input Data
-   Correct Output (Labels)

``` text
Input Data + Correct Output
             │
             ▼
         ML Algorithm
             │
             ▼
     Learned Model
```

Prediction:

``` text
New Input
    │
    ▼
Trained Model
    │
    ▼
Prediction
```

------------------------------------------------------------------------

# Why Machine Learning?

Many real-world problems are too complex to solve using manually written
rules.

Examples: - Email spam detection - Face recognition - Stock price
prediction - Recommendation systems - Speech recognition - Medical
diagnosis

------------------------------------------------------------------------

# What Does Machine Learning Learn?

``` text
Input (Features)
        │
        ▼
Hidden Pattern / Function
        │
        ▼
Output (Target)
```

Example:

    Hours Studied Pass?
  --------------- -------
                2 No
                4 No
                6 Yes
                8 Yes

The model learns the relationship between study hours and passing.

------------------------------------------------------------------------

# Two Main Goals

1.  Learn from past data.
2.  Generalize to unseen data.

# Types of Machine Learning

``` text
                Machine Learning
                      │
      ┌───────────────┼───────────────┐
      │               │               │
      ▼               ▼               ▼
Supervised     Unsupervised     Reinforcement
```

## 1. Supervised Learning

Uses **labeled data**.

Applications: - House price prediction - Disease prediction - Spam
detection - Loan approval

### Classification

Predicts **categories**.

Examples: - Spam / Not Spam - Pass / Fail - Cat / Dog

``` text
+++++
---------------- Decision Boundary
ooooo
```

### Regression

Predicts **continuous numerical values**.

Examples: - House price - Salary - Temperature

``` text
     •
   •
 •
      •
        •
-----------
Best Fit Line
```

### Classification vs Regression

  Classification       Regression
  -------------------- ------------------------
  Categorical output   Continuous output
  Spam detection       House price prediction

------------------------------------------------------------------------

## 2. Unsupervised Learning

Uses **unlabeled data**.

Applications: - Customer segmentation - Image compression - Topic
modeling

### Clustering

Groups similar data together.

### Anomaly Detection

Finds unusual observations (e.g., fraud detection).

``` text
○ ○ ○ ○ ○

    ●
```

### Dimensionality Reduction

Reduces the number of features while preserving useful information.

------------------------------------------------------------------------

## 3. Reinforcement Learning

An **agent** learns by interacting with an **environment** using rewards
and penalties.

``` text
      Reward
        ▲
        │
Environment ◄── Agent
     ▲          │
     └─ Action ─┘
```

Examples: - Self-driving cars - Robotics - Game AI

------------------------------------------------------------------------

# Comparison

  Feature   Supervised       Unsupervised    Reinforcement
  --------- ---------------- --------------- -----------------
  Data      Labeled          Unlabeled       Interaction
  Goal      Predict output   Find patterns   Maximize reward

------------------------------------------------------------------------

# Advantages

-   Learns automatically from data.
-   Handles complex problems.
-   Improves with more data.
-   Reduces manual rule writing.

# Limitations

-   Needs quality data.
-   Computationally expensive.
-   Can overfit or underfit.
-   Some models are hard to interpret.

------------------------------------------------------------------------

# Quick Revision

-   ML learns patterns from data.
-   Traditional Programming: **Data + Program → Output**
-   ML Training: **Data + Correct Output → Learned Model**
-   Supervised → Classification & Regression
-   Unsupervised → Clustering, Anomaly Detection, Dimensionality
    Reduction
-   Reinforcement → Reward-based learning
-   Good models generalize well to unseen data.
